# LightHouse Migrations

This page covers how to migrate between LightHouse versions when there are 
breaking changes.

!!! danger "Migration Order"
    
    When migrating from old versions always migrate one migration step at a 
    time. Do not directly migrate to the latest version. Follow the 
    migration guides of each version listed on the side.

!!! info

    Versions not listed here do not need migration steps.
